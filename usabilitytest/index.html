Help Me Test My Goodreads Dashboard

It takes about 20 minutes. You will attempt some short tasks, then answer two quick surveys.

Step 1

Welcome

You're here because I invited you to test a project I created as part of my masters program with Art Center School of Design. For this project, I wanted to create a dashboard for the Goodreads.com website. This is something that doesn't currently exist, but that I have always thought should exist. Let's see if I can fix that problem!

I am testing the design, not you! There are no wrong answers. If something is confusing, that's exactly what I need to know.

Your answers are used only for this graduate class project. I only ask your name so that I can follow up if needed. Actual results are reported without names or identifying information. You can skip any question that isn't marked required, or stop at any time.

Thank you for your help! I really appreciate it.
